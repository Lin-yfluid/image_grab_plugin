电商图片提取下载

在淘宝、京东、拼多多的商品详情页与商家后台，一键提取商品图，勾选后批量保存为 PNG。

淘宝 / 天猫 京东 拼多多商家版

能做什么

悬浮提取

仅在商品页右下角显示「获取图片」，扫描 img、srcset、懒加载属性与背景图。

智能过滤

自动去掉图标、Logo、占位图和小于 100×100 的图片，相对路径补全并去重。

勾选下载

新标签页网格预览，支持全选 / 反选，统一转为 PNG，文件名如 商品图_001.png。

安装步骤

  1. 打开 Chrome，访问 chrome://extensions
  2. 右上角开启「开发者模式」
  3. 点击「加载已解压的扩展程序」，选择本插件文件夹
  4. 工具栏出现橙色相机图标后即可使用

使用流程

  1. 打开淘宝 / 京东 / 拼多多商品详情或商家商品页
  2. 点击页面右下角「获取图片」
  3. 在弹出的图库中勾选需要的图片
  4. 点击「下载选中」，等待进度完成
