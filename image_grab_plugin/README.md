# 电商图片提取下载

Chrome Manifest V3 扩展：在淘宝、京东、拼多多的商品详情页与商家后台，一键提取商品图片，并在新标签页勾选后批量下载为 PNG。

## 安装

1. 打开 Chrome，访问 `chrome://extensions`
2. 开启右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本仓库根目录（包含 `manifest.json` 的文件夹）
5. 工具栏出现橙色图标即表示安装成功

点击工具栏图标可打开扩展内介绍页（官网）。

## 使用

1. 打开淘宝 / 天猫 / 京东 / 拼多多的商品详情页，或对应商家后台的商品页
2. 页面右下角会出现「获取图片」按钮（其他页面不显示）
3. 点击后扫描当前页商品图，并打开图库页
4. 勾选需要的图片（支持全选 / 反选）
5. 点击「下载选中」，等待进度提示完成
6. 文件保存到浏览器默认下载目录，命名为 `商品图_001.png`、`商品图_002.png` …

## 本地夹具测试

在仓库根目录执行：

```bash
python -m http.server 8765 --directory fixtures
```

浏览器打开 `http://127.0.0.1:8765/product.html`，应出现「获取图片」按钮。大图、srcset、懒加载与背景图会被提取；logo、小图标、1×1 图会被过滤。

## 权限说明

扩展需要 `downloads`、`storage`、`scripting` 以及淘宝 / 京东 / 拼多多域名和常见图片 CDN 的访问权限，以便跨域拉取原图并转换为 PNG。
